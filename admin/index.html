      Help and support

      A student forgot their password

      Open Password resets, click Generate temporary password and give it to the student in person. They must choose a new one at next login.

      Adding equipment fails or the photo is rejected

      Fill in every field and pick a JPG, PNG or WebP photo (it is shrunk automatically). If it still fails, make sure the server's uploads folder is writable.

      The page shows old data or an offline message

      Check the internet connection. The page refreshes by itself every few seconds once you are back online.

      Protecting the data

      Download a backup regularly from this page. Backups contain password hashes, so store them safely.
